### 01 / The person behind the pixels

I'm Ahmed. I build web interfaces and cross-platform applications,
with a focus on how they look, behave, and evolve.

My favorite problems live between design and engineering:
a complicated workflow that needs to feel simple, a component system
that needs room to grow, or an interface that needs to stay fast
as the product becomes more demanding.

**My aim: software that feels considered, all the way down.**

### 05 / Notes I build by

> An interface includes every state the user can reach.

The first render is the beginning. I care about what happens when
the connection slows down, the data is empty, an action fails,
or someone navigates with a keyboard.

> Reuse starts with understanding what should stay consistent.

I look for the patterns that deserve to become shared components
while leaving room for individual features to evolve.

> Small details deserve deliberate decisions.

Spacing, feedback, naming, and transitions all contribute to
how confidently someone can use a product.
